# Dashboard-Implementation-using-CAN
Developed an STM32F4-based IoT monitoring system using CAN for real-time sensor communication. Interfaced INA219, HX710B, DHT22, and LIS3DSH via I2C, SPI, and GPIO. Integrated ESP8266/ESP32 with MQTT and built an HTML dashboard for live monitoring using Embedded C, STM32 HAL, timers, and watchdogs.
